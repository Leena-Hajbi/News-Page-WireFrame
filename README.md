# News Page Wireframe

## 📌 Project Overview
This project presents a low-fidelity wireframe design for a news website homepage created using Figma.

## 🎯 Objective
To design a clean and structured layout for a modern news platform focusing on usability and content hierarchy.

## 🛠 Tools Used
- Figma
- UI/UX Design Principles

- Exported PDF version
